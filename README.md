# AIMS-mini

Ứng dụng dòng lệnh mẫu cho IT3180 – Nhập môn Công nghệ phần mềm.

## Chạy chương trình

```bash
python3 main.py
```

Kết quả tổng tiền: `Total cost: 63.89 $`.

## Yêu cầu

Python >= 3.10; chỉ dùng thư viện chuẩn.

## Kiểm thử (từ Lab 03)

```bash
python3 -m unittest discover -s tests -v
```
